关于联网与运行方式

本页面运行在 Claude 的 Artifact 沙箱中，调用 Anthropic API（含 Web Search 工具）无需你提供 API Key、无需部署，直接在本对话内即可联网调研。

若你希望把本页面导出到独立环境自行托管，需要改造为使用你自己的 API Key（浏览器直连 Anthropic API 通常会被 CORS 拦截，需要一个轻量后端转发），当前版本未内置该 fallback。

若遇到"Failed to fetch"：通常是瞬时网络问题或接口限流，v1.1.0 起已自动重试2次；若仍失败，对应模块会显示"重试"按钮，可单独重试，无需重新开始整个分析。
